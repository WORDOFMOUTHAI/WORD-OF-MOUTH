## First Time Setup

### System Requirements

**Minimum Requirements:**
- Modern web browser (Chrome 80+, Firefox 75+, Safari 13+, Edge 80+)
- 1024x768 screen resolution (mobile supported)
- JavaScript enabled
- 10MB available storage (for progress saving)

**Recommended:**
- Desktop or tablet for optimal experience
- Mouse or trackpad for geometry manipulation
- Keyboard for efficient flashcard reviews

### Getting Started

1. **Download** the `index.html` file from the repository
2. **Save** it to a convenient location on your device
3. **Double-click** the file to open in your default browser
4. **Bookmark** the page for easy access

**First Launch Checklist:**
- ✅ Application loads without errors
- ✅ All six tabs are accessible  
- ✅ Progress bar displays "0/30 lessons (0%)"
- ✅ Flashcards show default deck
- ✅ Geometry canvas responds to mouse/touch
- ✅ Graph input accepts expressions

### Accessibility Setup

**High Contrast Mode:**
1. Navigate to **Settings** tab
2. Click **"Toggle High Contrast"**
3. Interface switches to black background with white text
4. Setting saves automatically for future sessions

**Keyboard Navigation:**
- Use `Tab` to navigate between interactive elements
- `Enter` activates buttons and flips flashcards
- Arrow keys navigate within components
- `Shift + ?` shows keyboard shortcuts help

## Daily Learning Workflow

### Recommended 20-Minute Session

**Minutes 1-5: Progress Review**
1. Open **Progress** tab to see current status
2. Read today's lesson objective and activity
3. Click **"Mark Complete"** if you've finished yesterday's work
4. Select current lesson to review goals

**Minutes 6-12: Active Learning**
Choose one primary activity:
- **New Concepts**: Read lesson details and try the activity
- **Flashcard Review**: Practice spaced repetition cards
- **Visual Exploration**: Manipulate shapes in Geometry lab
- **Function Analysis**: Graph expressions related to current lesson

**Minutes 13-18: Teach-Back**
1. Navigate to **Teach-Back** tab
2. Select concept related to current lesson
3. Write 2-3 sentences explaining the concept
4. Use hints if needed, save reflection
5. Rate your understanding (1-3 scale)

**Minutes 19-20: Next Day Setup**
1. Review upcoming lesson briefly
2. Add any personal flashcards for difficult concepts
3. Check due flashcards for tomorrow's session

### Weekly Patterns

**Monday: Foundation Day**
- Focus on new concepts from current stage
- Create custom flashcards for unclear topics
- Use geometry to visualize abstract concepts

**Wednesday: Integration Day**  
- Review flashcards accumulated during the week
- Graph functions related to recent lessons
- Complete teach-back exercises for 2-3 concepts

**Friday: Synthesis Day**
- Review stage progress and completed lessons
- Challenge yourself with complex expressions in grapher
- Reflect on connections between different topics

**Weekend: Exploration**
- Experiment freely with all interactive features
- Revisit favorite geometry manipulations
- Try explaining concepts to friends or family

## Feature Deep Dive

### Progress Tracking Mastery

**Understanding Your Journey:**
The progress system tracks completion across four carefully designed stages:

**Stage 1 (Days 1-10): Foundation Reconstruction**
- Order of operations, variables, linear equations
- Basic geometry and proportional reasoning
- Focus: Building confidence with fundamentals

**Stage 2 (Days 11-18): Intermediate Integration**  
- Trigonometry, coordinate geometry, quadratics
- Advanced geometric concepts and transformations
- Focus: Connecting different mathematical areas

**Stage 3 (Days 19-25): Classical Mathematical Thinking**
- Euclidean geometry, golden ratio, Fibonacci
- Conic sections and formal proofs
- Focus: Historical context and deeper reasoning

**Stage 4 (Days 26-30): Sacred Geometry Synthesis**
- Geometric constructions and symbolism
- Advanced proofs and pattern recognition
- Focus: Aesthetic appreciation and mastery

**Strategic Lesson Selection:**
- **Sequential**: Follow 1→30 for structured progression
- **Targeted**: Jump to specific topics as needed
- **Spiral**: Revisit earlier concepts with new understanding
- **Challenge**: Skip ahead to test readiness

### Flashcard System Mastery

**Understanding the Algorithm:**
The spaced repetition system adapts to your performance:

**Rating Guide:**
- **Again (1)**: "I had no idea" - Card returns in 10 minutes
- **Hard (2)**: "I struggled but got it" - Shorter than normal interval
- **Good (3)**: "I knew it with some effort" - Standard progression
- **Easy (4)**: "I knew it immediately" - Longer interval

**Optimization Strategies:**
- **Be honest** with ratings - the algorithm depends on accuracy
- **Review regularly** - daily sessions build stronger retention
- **Create connections** - relate new cards to existing knowledge
- **Use context clues** - pay attention to tags and categories

**Custom Card Creation:**
```
Good Front: "What is the quadratic formula?"
Good Back: "x = [-b ± √(b²-4ac)] / (2a) for ax² + bx + c = 0"

Better Front: "Solve x² - 5x + 6 = 0 using the quadratic formula"  
Better Back: "a=1, b=-5, c=6 → x = [5 ± √(25-24)]/2 = [5 ± 1]/2 → x = 3 or 2"
```

### Geometry Lab Mastery

**Shape-Specific Techniques:**

**Triangle Mastery:**
- Drag vertices to create right, isosceles, or scalene triangles
- Observe how area changes with shape modifications
- Experiment with extreme triangles (very flat or very tall)
- Verify triangle inequality: sum of two sides > third side

**Rectangle Exploration:**
- Transform rectangles into squares by equalizing dimensions
- Explore perimeter vs. area relationship
- Create golden rectangles (ratio ≈ 1.618:1)
- Investigate how changing aspect ratio affects measurements

**Circle Investigation:**
- Drag radius handle to see circumference/area relationship
- Verify π relationship: C = 2πr, A = πr²
- Compare circle area to inscribed/circumscribed squares
- Explore how radius changes affect both measurements

**Cube Visualization:**
- Understand isometric projection principles
- Visualize 3D relationships in 2D representation
- Connect to volume and surface area formulas
- Relate to real-world 3D objects and construction

**Advanced Techniques:**
- **Estimation**: Guess measurements before reading display
- **Comparison**: Create multiple shapes and compare properties
- **Extremes**: Test very large or very small shapes
- **Precision**: Use zoom for detailed measurements

### Graphing System Mastery

**Expression Building:**
Start simple and build complexity:

**Level 1: Linear Functions**
```
x           (identity function)
2*x + 3     (slope-intercept form)
-x + 5      (negative slope)
```

**Level 2: Quadratic Functions**
```
x^2         (basic parabola)
x^2 - 4     (shifted down)
(x - 2)^2   (shifted right)
-x^2 + 3*x  (opens downward)
```

**Level 3: Trigonometric Functions**
```
sin(x)      (basic sine wave)
cos(x)      (basic cosine wave)
sin(2*x)    (frequency doubling)
sin(x) + cos(x)  (wave interference)
```

**Level 4: Advanced Combinations**
```
x^2 * sin(x)       (amplitude modulation)
sin(x) / x         (sinc function)
e^(-x) * cos(x)    (damped oscillation)
sqrt(x) * ln(x)    (composite functions)
```

**Navigation Mastery:**
- **Zoom Strategy**: Start zoomed out, then focus on interesting regions
- **Pan Technique**: Follow function curves by dragging
- **Intercept Hunting**: Look for red and green dots indicating roots
- **Analysis Reading**: Study step-by-step solutions in overlay

**Problem-Solving Workflow:**
1. **Plot** the basic function to see overall shape
2. **Zoom** to regions of interest (intercepts, extrema)
3. **Analyze** the provided steps for mathematical insights
4. **Experiment** with variations to test understanding
5. **Connect** to algebraic manipulation techniques

### Teach-Back System Mastery

**Effective Explanation Strategies:**

**The CLEAR Method:**
- **C**oncrete examples before abstract concepts
- **L**anguage appropriate for your imagined audience
- **E**rrors commonly made and how to avoid them
- **A**nalogies connecting to familiar experiences
- **R**eason why the concept matters or works

**Example Progression:**
```
Weak: "PEMDAS means do operations in the right order."

Better: "PEMDAS tells us to do parentheses first, then exponents, 
then multiplication and division left to right, then addition 
and subtraction left to right."

Excellent: "PEMDAS prevents ambiguity in math expressions. Without 
it, 2 + 3 × 4 could equal 20 or 14. We agree on PEMDAS so everyone 
gets 14. It's like grammar rules that make sentences clear. 
A common mistake is doing all multiplication before all division - 
instead, work left to right for equal-priority operations."
```

**Self-Assessment Calibration:**
- **Score 3**: Could teach this to someone else confidently
- **Score 2**: Understand but would need review before teaching
- **Score 1**: Need to study more before attempting explanation

## Learning Strategies

### Maximizing Retention

**Spaced Practice Schedule:**
- **Daily**: 15-20 minute focused sessions
- **Weekly**: One longer 45-60 minute integration session  
- **Monthly**: Complete stage review and reflection

**Active Recall Techniques:**
- Close the lesson details and try to remember objectives
- Explain flashcard answers before flipping
- Predict graph behavior before plotting
- Estimate geometry measurements before reading

**Multi-Modal Reinforcement:**
- **Visual**: Draw concepts on paper while using digital tools
- **Auditory**: Read explanations aloud during teach-back
- **Kinesthetic**: Use gestures while explaining mathematical operations
- **Social**: Discuss concepts with study partners or family

### Overcoming Challenges

**"I Don't Understand" Moments:**
1. **Break it down**: Focus on one small part
2. **Use analogies**: Connect to something familiar
3. **Visualize**: Use geometry or graphing tools
4. **Teach back**: Explain what you DO understand
5. **Take breaks**: Return with fresh perspective

**Mathematical Anxiety Management:**
- **Start small**: Begin with easier concepts to build confidence
- **Celebrate progress**: Acknowledge completion of each lesson
- **Growth mindset**: View mistakes as learning opportunities
- **Support system**: Share journey with encouraging friends/family

**Motivation Maintenance:**
- **Track streaks**: Maintain daily learning consistency
- **Variety**: Rotate between different features to stay engaged
- **Applications**: Look for math in daily life and hobbies
- **Community**: Join online forums or local math circles

### Advanced Learning Techniques

**Interleaving Practice:**
Instead of focusing on one topic for extended periods, mix topics:
- Alternate between flashcard review and new lesson content
- Switch between geometry and graphing within sessions
- Combine teach-back exercises from different stages

**Elaborative Interrogation:**
Ask yourself "why" and "how" questions:
- Why does this formula work?
- How does this connect to previous concepts?
- What would happen if I changed this parameter?

**Distributed Practice:**
Space out learning over time rather than cramming:
- Review yesterday's lesson before starting today's
- Revisit Stage 1 concepts while in Stage 3
- Use flashcard algorithm to enforce optimal spacing

## Troubleshooting

### Technical Issues

**Application Won't Load:**
1. Check browser compatibility (Chrome 80+, Firefox 75+, Safari 13+, Edge 80+)
2. Ensure JavaScript is enabled in browser settings
3. Try refreshing the page (Ctrl+F5 or Cmd+Shift+R)
4. Clear browser cache and reload
5. Try different browser if problems persist

**Canvas Not Responding:**
1. Check if mouse/trackpad is working properly
2. Try using keyboard navigation instead
3. Ensure canvas element is fully loaded (wait a few seconds)
4. Disable browser extensions that might interfere
5. Try zooming browser to 100% if display seems off

**Progress Not Saving:**
1. Check if localStorage is enabled in browser
2. Ensure sufficient disk space (need ~10MB)
3. Try export/import to backup and restore data
4. Check if browser is in incognito/private mode
5. Verify site permissions allow data storage

**Performance Issues:**
1. Close other browser tabs to free memory
2. Restart browser if application becomes slow
3. Disable hardware acceleration if graphics glitch
4. Update browser to latest version
5. Try on different device to isolate hardware issues

### Learning Difficulties

**Flashcards Feel Too Hard:**
- Rate more cards as "Again" to increase review frequency
- Create easier custom cards to build confidence
- Focus on understanding rather than memorization
- Use teach-back system to reinforce difficult concepts

**Geometry Seems Confusing:**
- Start with simple shapes (triangle, rectangle)
- Focus on one measurement at a time (area OR perimeter)
- Use zoom feature to see small changes clearly
- Connect to real-world objects (room dimensions, pizza slices)

**Graphing Expressions Fail to Parse:**
- Check syntax: use * for multiplication (2*x not 2x sometimes)
- Verify parentheses are balanced
- Use supported functions only (see documentation)
- Start with simple expressions and build complexity

**Teach-Back Feels Overwhelming:**
- Use progressive hints generously
- Start with familiar concepts
- Write just one sentence initially
- Focus on explaining to yourself first

### Data Management Issues

**Lost Progress After Browser Update:**
1. Check if localStorage still contains data
2. Look for exported backup files
3. Try import function with any backup data
4. Restart from convenient checkpoint if necessary

**Want to Transfer Between Devices:**
1. Use Export function on original device
2. Save JSON file to cloud storage or email
3. Download file on new device  
4. Use Import function to restore progress

**Accidentally Reset All Data:**
1. Check browser back button (may restore session)
2. Look for automatic backup files
3. Restart with fresh motivation if needed
4. Consider it a chance to improve learning strategies

## Frequently Asked Questions

### General Usage

**Q: How long does it take to complete all 30 lessons?**
A: At 15-20 minutes per day, you can complete the journey in about a month. However, learning is more important than speed - take as long as you need.

**Q: Can I skip lessons or jump around?**
A: Yes! The system is flexible. However, lessons build on each other, so skipping may make later concepts more challenging.

**Q: Do I need an internet connection?**
A: No, once you've downloaded the HTML file, everything works offline. Your progress saves locally.

**Q: Can multiple people use the same application?**
A: The app stores one progress profile per browser. For multiple users, either use different browsers or export/import profiles.

### Learning Approach

**Q: I haven't done math in years. Is this too advanced?**
A: The journey starts with fundamentals and builds gradually. Stage 1 is designed specifically for adults returning to mathematics.

**Q: What if I get stuck on a concept?**
A: Use the teach-back hints, try the geometry visualizations, or move to a different topic and return later. Learning isn't always linear.

**Q: How do I know if I really understand something?**
A: The teach-back system is designed for this. If you can explain a concept clearly to someone else, you truly understand it.

**Q: Should I memorize formulas?**
A: Focus on understanding first. The flashcard system will help with memorization, but comprehension is more important than rote learning.

### Technical Questions

**Q: Why is this a single HTML file instead of a website?**
A: This design ensures the app works anywhere - no server required, no updates breaking functionality, and complete privacy since nothing is transmitted.

**Q: Can I modify the lessons or add content?**
A: Yes! The code is well-documented and modular. See the technical documentation for customization guidance.

**Q: Does this work on mobile devices?**
A: Yes, the interface is responsive and includes touch support. However, some features (like geometry manipulation) work better on larger screens.

**Q: How is my privacy protected?**
A: All data stays on your device. Nothing is transmitted to servers or external services. Your learning progress is completely private.

### Advanced Usage

**Q: Can I integrate this with other learning systems?**
A: The export/import functionality uses standard JSON, making integration possible with some technical knowledge.

**Q: How accurate are the mathematical calculations?**
A: The application uses standard JavaScript mathematical functions, which are suitable for educational purposes but may have floating-point precision limits.

**Q: Can I add my own flashcards permanently?**
A: Yes, use the "Add Card" feature. Custom cards integrate fully with the spaced repetition system and are saved with your progress.

**Q: What mathematical level does this cover?**
A: Roughly equivalent to pre-algebra through algebra II, with some geometry and trigonometry. Suitable for high school review or adult education.
